# Fontes de dados e referências

- NHL Web API roster: https://api-web.nhle.com/v1/roster/{TEAM}/current
- NHL Web API prospects: https://api-web.nhle.com/v1/prospects/{TEAM}
- NHL asset logos: https://assets.nhle.com/logos/nhl/svg/{TEAM}_dark.svg
- NHL Stanley Cup champions: https://www.nhl.com/news/topic/playoffs/nhl-stanley-cup-champions-winners-complete-list-287705398
- NHL Member Clubs / arenas: https://www.nhl.com/info/nhl-affiliates-member-clubs

Observação: nomes comerciais de algumas arenas podem mudar por naming rights; a base do app foi ajustada
para refletir nomes conhecidos na temporada 2026–27 quando havia mudança pública relevante.
